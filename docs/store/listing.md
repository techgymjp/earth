# Google Play ストア掲載情報（下書き）

Play Console の「ストアの掲載情報」に貼り付けて使います。既定の言語を日本語にし、「翻訳を管理」から英語（en-US）を追加してください。
英語版の詳しい説明は `listing-en.txt` にあります。

- パッケージ名: `jp.techgym.earth`
- カテゴリ: ゲーム ＞ 教育（または ゲーム ＞ クイズ）
- タグ: 地理、クイズ、教育、トリビア など（Play Console で選べるものから）
- プライバシーポリシー: 日本語 https://techgym.jp/privacy-policy/ ・英語 https://techgym.jp/privacy-policy-en/
- ホーム画面に出る名前は「国探し」（英語の端末では「Find Country」）。ストアのアプリ名とは別です

## 日本語

**アプリ名**（30 文字以内・21 文字）

```
国探し - 地球儀で国当て 世界地理クイズ
```

**簡単な説明**（80 文字以内・65 文字）

```
地球儀をくるくる回して、お題の国を探す世界地理クイズ！世界地図と国の位置が楽しく覚えられる。全10問のタイムアタックで脳トレにも。
```

**詳しい説明**

```
「ブラジルを探して！」「クロアチアを探して！」
リアルな地球儀をくるくる回して、お題の国を見つけてタップする世界地理クイズです。
国の位置を覚えたい人、世界地図が好きな人、旅行好きの人、地理の勉強や大人の学び直しにもぴったり。

■ 遊び方
・指でドラッグして地球を回し、ピンチで拡大・縮小
・お題の国を見つけたらタップ！
・3回まちがえるとハートがなくなり、正解の国が表示されます
・まちがえた国も「そこは〇〇です」と名前がわかるので、遊ぶほど世界の国が覚えられます

■ 全10問のタイムアタック
・1問ごとにタイムを計測。早く見つけるほど高得点
・ヒント（どの地域か → だいたいの位置）とパスもあり
・結果画面で正解数・合計タイム・称号を表示。ベストスコアも記録

■ 3つの難易度
・かんたん：国境線つきの地球で、有名な国を探す
・ふつう：国境線なし。有名な国から中くらいの国まで
・むずかしい：国境線なし。バルト三国やカリブ海・太平洋の島国など、マニアックな国が出題

■ 地域をしぼって練習できる
全世界・アジア・ヨーロッパ・アフリカ・北アメリカ・南アメリカ・オセアニアから選べます。
苦手な地域だけを集中して覚えるのにも便利です。

■ 宇宙に浮かぶリアルな地球
・NASA の衛星画像をもとにした、本物そっくりの地球儀
・星空の宇宙に浮かぶ地球を、好きな角度から眺められる
・宇宙をイメージした BGM と効果音

■ その他
・約200の国と地域を収録（バチカンやツバルのような小さな国も）
・スコアを友だちにシェア
・ハートがなくなったとき、広告を見てハートを1つ回復できる（1ゲーム3回まで）
・オフラインでも遊べる（広告・シェアは通信が必要）
・日本語・英語に対応

あなたは世界の国をいくつ見つけられますか？
```

## ASO（ストア内検索）のための工夫

| 欄 | 入れたキーワード | 考え方 |
| --- | --- | --- |
| アプリ名 | 国探し・地球儀・国当て・世界地理・クイズ | 検索で最も重みが大きい欄。ゲーム名のあとに、何のアプリかがわかる検索語を並べた |
| 簡単な説明 | 地球儀・世界地理クイズ・世界地図・国の位置・タイムアタック・脳トレ | ストアの一覧でも表示される。最初の一文で遊び方がわかるようにした |
| 詳しい説明 | 国の位置・世界地図・地理の勉強・大人の学び直し・旅行・国境線・アジア/ヨーロッパなど地域名・バルト三国・島国 | 同じ語のくり返しは逆効果なので、自然な文章の中に関連語を散らした |
| 英語 | Globe・Quiz・3D globe・world map・geography quiz・time attack | 英語圏でよく検索される "geography quiz" "world map" を名前と説明に |

- 「子ども」「小学生」向けの言葉は入れていません（ターゲットを 13 歳以上にしているため。13 歳未満向けと受け取られると広告に制限がかかります）
- スクリーンショットの上のキャッチコピーにも、地理クイズ・世界地図などの言葉を入れています（画像内の文字も検索の参考にされることがあり、何より一覧で見たときに何のアプリかがすぐわかる）
- 公開後は Play Console の「ストアのパフォーマンス」で検索語ごとの流入を見て、名前や説明の語を入れ替えていくとよい（「ストアの掲載情報のテスト」で A/B テストもできる）
